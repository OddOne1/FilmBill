# DM Sans (self-hosted)

`DMSans-Variable.woff2` is the upright variable font (axes `opsz` 9–40,
`wght` 100–1000) from google/fonts, `ofl/dmsans/DMSans[opsz,wght].ttf`
(git blob `c672f98060af9b2c85fca704ebd5ad9a8717c1df`), converted to WOFF2
with fontTools 4.55.3. Format conversion only: no subsetting, no glyph or
name changes.

Licensed under the SIL Open Font License 1.1 — full text in `OFL.txt`
(google/fonts, blob `4430b85ac62998e2edb914360f9ebdfe43f4deaa`).
Loaded by `app/layout.tsx` via `next/font/local`.
